# Preguntas para la reunión con el Cuerpo de Bomberos y el tutor

Organiza la reunión: **Santiago**. Las respuestas se anotan en `reglas-de-negocio.md` y se avisa al responsable.

## Alcance (para el tutor)
1. ¿Hay que entregar los 41 requisitos o se acepta una entrega por fases?
2. ¿Cuál es la fecha de entrega y qué se evalúa (sistema, informe, capacitación)?
3. ¿El sistema se va a publicar en un servidor de la institución o basta con una demo?

## Datos
4. ¿Hay que migrar los datos actuales de GESADMEN? ¿En qué base de datos están (SQL Server, MySQL, otra)?
5. ¿Nos pueden dar datos de ejemplo (sin información personal real) para las pruebas?
6. ¿De dónde sale el avalúo de cada predio? ¿Lo da el municipio? ¿Cambia cada año?

## Cálculos
7. ¿Cómo se calculan los intereses por mora (tasa y desde cuándo corren)?
8. ¿Cómo se calcula la multa?
9. ¿Qué descuentos existen y a quién se aplican?
10. ¿El mínimo de $1.25 se compara contra el valor antes o después del descuento?
11. ¿Cómo se calcula el valor del permiso de funcionamiento?

## Procesos
12. ¿Quién puede anular un comprobante? ¿Hay límite de tiempo para hacerlo?
13. Si el contribuyente tiene deuda, ¿se le puede emitir el certificado de solvencia o se bloquea?
14. ¿Qué datos se registran en cada forma de pago (banco, número de cheque, voucher)?
15. ¿Cuántos puntos de emisión y cuántos recaudadores hay?
16. ¿Nos pueden mostrar un comprobante, un certificado y un corte de caja impresos de ejemplo?

## Caja
19. ¿Qué se hace si el arqueo no cuadra con lo cobrado en efectivo?
20. ¿El corte de caja cierra el día para ese recaudador?

## Portal ciudadano
21. ¿Qué debe poder hacer el contribuyente al entrar: consultar sus deudas, descargar comprobantes, pedir un certificado?
22. ¿Se requiere pago en línea?
